# 3 ジョブ横断バランス比較（Milestone 9-A）

> **M9-A.1 での位置づけ**: 本ファイルの「測定の限界」（fire / frost の弾未解決・warrior 別尺度）は
> **M9-A.1 の production 駆動ハーネスで解消した**。絶対比較の最新の正は
> `./cross-job-final-balance.md`。本ファイルの数値（火:氷 2.72 等）は M9-A 時点の
> 見かけ値として歴史的記録のまま残す（旧ハーネスは非回帰ハッシュの土台として維持）。

同一条件（共通 battle profile）で 3 ジョブを回した比較。**目的は構造異常の検出であって、
ジョブを同じ数値へ揃えることではない。** バランス値の変更は 0 件。

## 測定の限界（documented note・比較の読み方）

- **fire / frost の弾（projectile）ダメージはヘッドレスの Scene モックでは解決されない**
  （弾は生成のみ記録され、命中はしない）。火は 1200 step で弾 2,000 発超を生成するため、
  「即時ダメージイベント量」は火が実際より小さく出る。
- **戦士のダメージは近接モックが全量解決する**別尺度で、火 / 氷と直接比較できない
  （M8-B から記録されている 3 ジョブ共通の制約）。
- したがって**ジョブ間 DPS 比は回帰検知フェンス（≤ 4.0）としてだけ**使い、
  バランス判定は per-job の completion スイート（実データ由来の比較）と実ブラウザに委ねる。

- 死にスキル 0 / utility 0 = 0 / 一極集中なし / 永久状態なし —— **構造異常は 3 ジョブとも 0 件**。
