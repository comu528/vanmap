# 人間プレイテスト ゲート（Milestone 9-A.2・external manual gate）

**自動操作では判定できない項目**をここに残す。M9-A.2 の自動プレイテストが確認したのは
「壊れていない・数値が期待どおり・構造が揃っている」までで、**面白さ・爽快感・難易度の妥当性は
一切判定していない**。以下は人間が実際に遊んで初めて答えが出る。

- 自動で確認した範囲: `./browser-longrun-results.md`
- 判定と分類: `./final-balance-verdict.md`
- 手順の土台: `./browser-longrun-playtest.md` §1–2（環境と共通条件）

> このゲートは **open（未実施）** のまま M9-A.2 を完了する。
> 埋まっていないことを理由に balance を動かさない（`human-feel` 分類は修正の根拠にしない）。

---

## 1. 実施方法

1. `npx http-server -p 8123 -c-1` でリポジトリを配信し、`http://127.0.0.1:8123/index.html` を開く
   （デバッグ表示が要るときだけ `?debug=1`）。
2. **恒久強化なし・Job Lv 1 の新規セーブ**で 3 ジョブを 1 周ずつ、手入力（WASD / SPACE / Q / ESC）で遊ぶ。
   オート移動は**切って**遊ぶ（自動プレイテストはオート移動を使っている）。
3. 次に**恒久強化を進めた状態**で 3 ジョブを 1 周ずつ遊び、ボス到達までの手応えを見る。
4. 品質 `low` と `ultra` を切り替えて同じ場面を見比べる。
5. 下表を埋めて、`./browser-longrun-results.md` の human gate 節へ結果を追記する。

## 4. このゲートが埋まったら

- `./final-balance-verdict.md` の `human-feel` 分類へ結果を反映する。
- **人間評価が「NG」だった項目だけ**が balance 変更の検討対象になる。
