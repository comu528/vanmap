# テストガイド（GitHub Pages 上での確認項目）

GitHub Pages に公開後、Chrome 系ブラウザで公開 URL を開き、以下を確認する。
（Milestone 1〜4・M5-A（空間グリッド・性能計測）・M5-B（フォルダ保存・バックアップ・JSON入出力・競合解決）の範囲。
時間短縮には URL に `?debug=1` を付けて F1 のテスト機能・F2 性能パネル・F3 グリッド可視化・データ管理の ⚙debug が使える。）

## 起動

- [ ] 「はじめから/続きから/拠点/データ管理/設定」が並ぶ
