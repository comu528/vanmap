# テストガイド（GitHub Pages 上での確認項目）

GitHub Pages に公開後、Chrome 系ブラウザで公開 URL を開き、以下を確認する。
（Milestone 1〜2 の範囲。M3 以降の項目は未実装。）

## 起動
- [ ] タイトル画面が表示される（タイトル文字 / 火の粉演出）
- [ ] 「はじめから/続きから/拠点/データ管理/設定」が並ぶ
- [ ] 途中セーブが無い状態で「続きから」が **灰色（無効）** になっている
- [ ] 左下にバージョン、保存状態（ブラウザ保存: 有効 / フォルダ未接続）が出る
- [ ] 画面右上の ⛶ ボタン、または Shift+F で全画面が切り替わる
- [ ] ウィンドウを拡大縮小してもアスペクト比が維持され、ピクセルがぼやけない

## 戦闘（はじめから）
- [ ] 魔女（紫の帽子・赤いローブ）が中央に表示される
- [ ] WASD / 矢印キーで移動できる
- [ ] Space でダッシュできる（左下のダッシュ残量 ◆ が減り、時間で回復）
- [ ] しばらくすると敵（スライム/コウモリ）が画面外から出現し、プレイヤーへ向かう
- [ ] 敵が攻撃範囲に入ると火球が自動発射され、命中で小爆発する
- [ ] 敵を倒すと破片エフェクトが出て、経験値ジェム（水色）が落ちる
- [ ] ジェムに近づくと吸い寄せられ、経験値バーが増える
- [ ] レベルアップで画面が暗転し、**3つの候補**が出る
- [ ] 候補は数字キー 1〜3 でもクリックでも選べる
- [ ] 選択後にゲームが再開し、火球が強化される（火球強化を選んだ場合）
- [ ] HUD に HP / 経験値 / Lv / 経過時間 / 討伐数 / 難易度 / 所持スキル が表示される

## 一時停止・中断
- [ ] Escape または画面内「停止」ボタンで一時停止し、敵・弾・タイマーが止まる
- [ ] 一時停止中に「再開」ボタンで再開できる
- [ ] 別タブに切り替える / ウィンドウのフォーカスを外すと自動停止する
- [ ] 復帰しても勝手に再開せず、再開ボタンが表示される

## スキル（M2）
- [ ] レベルアップで「【新】○○」を選ぶと新しいスキルを取得できる（火柱/燃える軌跡/周回する炎/隕石）
- [ ] 既に持っているスキルは「○○ Lv.n」の強化として出る（新規重複取得はされない）
- [ ] 各スキルが Lv8 まで上がり、発射数・範囲・見た目などが変化する
- [ ] 火球（自動発射＋小爆発）/ 火柱（予告→発生）/ 燃える軌跡（足元に炎）/ 周回する炎（周囲を回る火球）/
      隕石（予告→落下＋画面揺れ）がそれぞれ動作する

## ボス・リザルト（M2）
- [ ] 5分（5:00）到達でボス（専用の大きな赤い姿）が出現し、上部にボスHPバーが出る
- [ ] ボスが突進・円形の弾ばらまき・雑魚召喚を行う
- [ ] ボスHPが半分以下で「激昂」し攻撃が激化する
- [ ] ボス撃破でリザルト（勝利）へ進む
- [ ] プレイヤー死亡でリザルト（敗北）へ進む
- [ ] リザルトに 生存時間/討伐数/ボス討伐数/最高ダメージ/スキル別の与ダメージ・討伐数 が出る
- [ ] 「再挑戦」で戦闘をやり直せる／「タイトルへ」でタイトルに戻れる

## 演出・設定（M2）
- [ ] 攻撃時にダメージ数字・パーティクル・爆発・被弾フラッシュ・画面揺れが出る
- [ ] 一時停止メニューでエフェクト品質（low/medium/high/ultra）やダメージ数字・画面揺れを切り替えられる
- [ ] 品質を low にしても敵は同じように倒せる（演出だけ減り、戦闘結果は変わらない）

## オート移動（M2）
- [ ] Q キー（または画面内ボタン）でオート移動 ON にすると、敵から離れつつジェムを拾うように動く
- [ ] 手動でキーを押している間は手動操作が優先される

## 途中再開（M2）
- [ ] 戦闘を少し進めてから、ブラウザを再読み込みする
- [ ] タイトルの「続きから」が有効になっている
- [ ] 「続きから」で、経過時間・レベル・HP・所持スキルが概ね元の状態で再開する
- [ ] 勝敗が確定した後は「続きから」が無効に戻る（途中セーブが消える）

## その他
- [ ] `?debug=1` を URL に付けても通常プレイに影響しない（パネルは M5）

## データ検証（CI）
- [ ] `.github/workflows/validate.yml` が push/PR で成功する（`node tests/validate-data.mjs`）
