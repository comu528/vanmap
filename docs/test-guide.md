# テストガイド（GitHub Pages 上での確認項目）

GitHub Pages に公開後、Chrome 系ブラウザで公開 URL を開き、以下を確認する。
（Milestone 1〜4 の範囲。M5 以降の項目は未実装。時間短縮には URL に `?debug=1` を付けて F1 のテスト機能が使える。）

## 起動
- [ ] タイトル画面が表示される（タイトル文字 / 火の粉演出）
- [ ] 「はじめから/続きから/拠点/データ管理/設定」が並ぶ
- [ ] 「はじめから」または「拠点」で**拠点画面**へ移動する
- [ ] 途中セーブが無い状態で「続きから」が **灰色（無効）** になっている
- [ ] 左下にバージョン、保存状態（ブラウザ保存: 有効 / フォルダ未接続）が出る
- [ ] 画面右上の ⛶ ボタン、または Shift+F で全画面が切り替わる
- [ ] ウィンドウを拡大縮小してもアスペクト比が維持され、ピクセルがぼやけない

## 戦闘（はじめから）
- [ ] 魔女（紫の帽子・赤いローブ）が中央に表示される
- [ ] WASD / 矢印キーで移動できる
- [ ] Space でダッシュできる（左下のダッシュ残量 ◆ が減り、時間で回復）
- [ ] しばらくすると敵（スライム/コウモリ）が画面外から出現し、プレイヤーへ向かう
- [ ] 敵が攻撃範囲に入ると火球が自動発射され、命中で小爆発する
- [ ] 敵を倒すと破片エフェクトが出て、経験値ジェム（水色）が落ちる
- [ ] ジェムに近づくと吸い寄せられ、経験値バーが増える
- [ ] レベルアップで画面が暗転し、**3つの候補**が出る
- [ ] 候補は数字キー 1〜3 でもクリックでも選べる
- [ ] 選択後にゲームが再開し、火球が強化される（火球強化を選んだ場合）
- [ ] HUD に HP / 経験値 / Lv / 経過時間 / 討伐数 / 難易度 / 所持スキル が表示される

## 一時停止・中断
- [ ] Escape または画面内「停止」ボタンで一時停止し、敵・弾・タイマーが止まる
- [ ] 一時停止中に「再開」ボタンで再開できる
- [ ] 別タブに切り替える / ウィンドウのフォーカスを外すと自動停止する
- [ ] 復帰しても勝手に再開せず、再開ボタンが表示される

## スキル（M2）
- [ ] レベルアップで「【新】○○」を選ぶと新しいスキルを取得できる（火柱/燃える軌跡/周回する炎/隕石）
- [ ] 既に持っているスキルは「○○ Lv.n」の強化として出る（新規重複取得はされない）
- [ ] 各スキルが Lv8 まで上がり、発射数・範囲・見た目などが変化する
- [ ] 火球（自動発射＋小爆発）/ 火柱（予告→発生）/ 燃える軌跡（足元に炎）/ 周回する炎（周囲を回る火球）/
      隕石（予告→落下＋画面揺れ）がそれぞれ動作する

## ボス・リザルト（M2）
- [ ] 5分（5:00）到達でボス（専用の大きな赤い姿）が出現し、上部にボスHPバーが出る
- [ ] ボスが突進・円形の弾ばらまき・雑魚召喚を行う
- [ ] ボスHPが半分以下で「激昂」し攻撃が激化する
- [ ] ボス撃破でリザルト（勝利）へ進む
- [ ] プレイヤー死亡でリザルト（敗北）へ進む
- [ ] リザルトに 生存時間/討伐数/ボス討伐数/最高ダメージ/スキル別の与ダメージ・討伐数 が出る
- [ ] 「再挑戦」で戦闘をやり直せる／「タイトルへ」でタイトルに戻れる

## 演出・設定（M2）
- [ ] 攻撃時にダメージ数字・パーティクル・爆発・被弾フラッシュ・画面揺れが出る
- [ ] 一時停止メニューでエフェクト品質（low/medium/high/ultra）やダメージ数字・画面揺れを切り替えられる
- [ ] 品質を low にしても敵は同じように倒せる（演出だけ減り、戦闘結果は変わらない）

## オート移動（M2）
- [ ] Q キー（または画面内ボタン）でオート移動 ON にすると、敵から離れつつジェムを拾うように動く
- [ ] 手動でキーを押している間は手動操作が優先される

## 途中再開（M2）
- [ ] 戦闘を少し進めてから、ブラウザを再読み込みする
- [ ] タイトルの「続きから」が有効になっている
- [ ] 「続きから」で、経過時間・レベル・HP・所持スキルが概ね元の状態で再開する
- [ ] 勝敗が確定した後は「続きから」が無効に戻る（途中セーブが消える）

## 拠点（M3）
- [ ] タイトル →「はじめから/拠点」で拠点画面が開く
- [ ] 上部タブ「概要 / 恒久強化 / 難易度 / 熟練度」を切り替えられる
- [ ] 「概要」に 残り火 / 累計残り火 / 選択・解放難易度 / 基礎能力 / 累計統計が出る
- [ ] 「戦闘開始」で選択中の難易度の戦闘が始まる

## 残り火・リザルト（M3）
- [ ] 戦闘を終える（勝利/敗北どちらでも）とリザルトに「今回獲得 残り火」と内訳が出る
- [ ] 敗北時も残り火を獲得できる（勝利時より少ない）
- [ ] リザルトの「拠点へ戻る」で拠点に戻り、残り火が加算されている
- [ ] 同じ結果画面を開き直しても残り火が二重に増えない（内部で一度きり加算）

## 恒久強化（M3）
- [ ] 拠点「恒久強化」で各項目の 現在Lv/最大Lv/現在効果→次効果/必要残り火/購入可否 が出る
- [ ] 残り火が足りる項目を購入するとレベルが上がり残り火が減る（即保存）
- [ ] 残り火が足りない項目は「不足」で購入できない／最大Lvは「MAX」表示
- [ ] 一部項目は難易度クリアで解放（未解放は 🔒 表示）
- [ ] 恒久強化した後の戦闘で、実際に強く（例: 最大HPが増える）なっている

## 難易度（M3）
- [ ] 拠点「難易度」で 難易度1〜5 が並び、未解放は 🔒 で選択できない
- [ ] 難易度1で勝利すると難易度2が解放される（敗北では解放されない）
- [ ] 難易度を上げると敵が固く・多くなり、獲得残り火の倍率が上がる

## スキル熟練度（M3）
- [ ] 拠点「熟練度」で各スキルの 熟練度Lv/次までの進捗/累計ダメージ・討伐/現在ボーナス が出る
- [ ] 戦闘でスキルを使うと統計が増え、拠点に戻っても（周回をまたいで）保持される

## スキル進化（M4）
- [ ] 火球Lv8＋周回する炎Lv4 まで上げると、レベルアップ時に金枠の「★進化 業火弾幕」候補が出る（`?debug=1`＋F1で近道）
- [ ] 進化を選ぶと専用演出（暗転→前後の名称→白フラッシュ→説明）が出て、クリック/Enter で戦闘再開する
- [ ] 演出中は敵・弾・タイマーが止まっている
- [ ] 進化後は火球枠が「業火弾幕」に置き換わり、扇状連射・撃破時の追撃火球・連鎖爆発になる
- [ ] 同様に 火柱→煉獄噴火 / 燃える軌跡→永劫火界 も進化できる（補助スキル条件を満たす）
- [ ] 拠点「熟練度」で該当スキルの「進化N回」が増えている

## 転生（M4）
- [ ] 拠点に「転生」タブがあり、条件未達ではロック（進捗表示）で転生できない
- [ ] 難易度3をクリア（または今周回で残り火5000）すると転生できるようになる
- [ ] 「転生する…」→ 確認画面が出て、キャンセルできる／最終確認で実行される（二段階）
- [ ] 転生すると 残り火・恒久強化・難易度解放 がリセットされ、魂炎が増える
- [ ] 転生後も 転生回数・魂炎・熟練度累計・統計・過去最高難易度 は保持される
- [ ] 転生直後でも難易度1をある程度進められる（極端に弱くなりすぎない）

## 魂炎強化（M4）
- [ ] 拠点「魂炎強化」で各項目の 現在/最大Lv・現在→次効果・必要魂炎・前提・購入可否 が出る
- [ ] 魂炎が足りれば購入でき（即保存）、足りなければ「不足」で買えない
- [ ] 「選択肢拡張」を買うと次の戦闘でレベルアップ候補が4択になる
- [ ] 「初期スキルレベル」で開始時の火球レベルが上がる（最大Lvは超えない）
- [ ] 「倍速モード」を買うと一時停止メニュー/概要で 1.5倍・2倍 を選べ、タイマー/CDが破綻しない
- [ ] 「オートダッシュ」を買うとオート移動中に危険で自動ダッシュ（ダッシュ回数を消費）

## 拠点スクロール（M4）
- [ ] 項目が多いタブ（恒久強化/魂炎強化）でホイール・ドラッグ・スクロールバー・上下キーでスクロールできる
- [ ] タブを切り替えるとスクロール位置が先頭に戻り、UIが画面外へはみ出さない

## その他
- [ ] `?debug=1` を URL に付けても通常プレイに影響しない。F1（または画面内⚙debug）で最小テスト機能が開く
- [ ] 通常URL（`?debug=1` なし）ではデバッグ機能が表示されない

## データ検証（CI）
- [ ] `.github/workflows/validate.yml` が push/PR で成功する（`node tests/validate-data.mjs`）
